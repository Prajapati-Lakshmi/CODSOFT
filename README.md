# # CodSoft C++ Programming Internship Projects

## 📘 About the Repository
This repository contains the projects completed during my C++ Programming Internship at CodSoft. The main objective of these projects is to strengthen programming fundamentals, improve logical thinking, and gain practical experience in C++ development.  

Each project focuses on implementing important programming concepts such as functions, loops, conditions, arrays, and object-oriented programming in C++.

---

# 🚀 Projects Included

## 🔹 1. Simple Calculator
The Simple Calculator is a basic C++ application that performs arithmetic operations such as addition, subtraction, multiplication, and division. This project helps in understanding conditional statements, functions, and user input handling in C++.

---

## 🔹 2. Number Guessing Game
The Number Guessing Game is an interactive C++ program where the computer generates a random number and the user attempts to guess it correctly. The program provides hints if the guessed number is too high or too low.  

This project demonstrates:
- Random number generation
- Loop implementation
- Conditional statements
- User interaction in C++

---

## 🔹 3. To-Do List Application
The To-Do List Application is a simple task management program that allows users to add, view, and remove tasks. This project helps in understanding lists, loops, and function implementation in C++ while creating a useful real-life application.
